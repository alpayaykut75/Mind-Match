<product_requirements>
The user aims to develop a mobile word-association game called Mind-Match. The core game involves two players (or player vs. AI) providing single-word associations based on the last two words. Key features include:

*   **User Management:** Sign-up, profile creation (bio, age, country, avatar), username and password changes.
*   **Friend System:** Sending/receiving friend requests, a detailed modal for friend requests showing user info (avatar, username, level, bio, age, country), and options to accept/reject requests.
*   **AI Opponent:** An AI that generates semantically associated words, avoids repetition, and aims for convergence.
*   **Game Mechanics:** Player vs. AI, player vs. player, tracking stats (successful syncs, streak, connection score), and earning badges.
*   **Leaderboard:** A dedicated screen to show top players, accessible from the home screen.
*   **User Experience (UX):** Implementation of country/age selection via dropdowns, a multi-select language option in the profile, and future plans for in-game language selection to facilitate matching.
*   **Cosmetic Enhancements:** Addition of sound effects and animations.
*   **Deployment:** The user is interested in the process for testing with friends (via EAS builds/TestFlight) and publishing to App Store/Play Store.
The current implementation includes a working sign-up, functional API endpoints for core features, a basic profile page displaying stats and badges, and a friend system with a detailed request modal.
